# FounderOS

FounderOS is an AI-powered startup idea validation platform. Founders enter an idea and receive an investor-grade analysis generated by eight autonomous agents, with live progress streamed to the UI.

## Stack

- React 18, Vite, Tailwind CSS, Framer Motion, Recharts
- Express.js, Socket.IO, MongoDB
- Flask AI microservice
- Google Gemini 1.5 Flash

## Prerequisites

- Node.js 18+
- Python 3.10+
- MongoDB running locally at `mongodb://localhost:27017/founderos`
- A Gemini API key for live AI output

## Setup

1. Copy environment files:

```bash
cp .env.example server/.env
cp .env.example ai-service/.env
```

2. Install Node dependencies:

```bash
npm run install:all
```

3. Install Python dependencies:

```bash
cd ai-service
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

4. Start MongoDB locally.

5. Start the AI service:

```bash
cd ai-service
python app.py
```

6. Start the web app and API from the repo root:

```bash
npm run dev
```

The client runs at `http://localhost:5173`, the Express API at `http://localhost:5000`, and Flask at `http://localhost:8000`.

## Notes

- If `GEMINI_API_KEY` is missing, the Flask service uses a deterministic premium-quality local fallback so the complete product flow remains testable.
- Analysis runs are persisted in MongoDB and can be retrieved by report ID.
- Socket.IO powers live agent progress updates.
